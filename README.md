# Drill Deck

Flashcards with a simple spaced-review loop. No backend, no API keys.

**Live demo:** [https://invenitur42.github.io/drill-deck/](https://invenitur42.github.io/drill-deck/)

## What you can do

- Create decks and cards
- Study due cards (flip, then Again / Good)
- Again brings a card back soon; Good stretches the interval

Data is stored in `localStorage`.

## Files

| File | Role |
|------|------|
| `index.html` | Markup |
| `styles.css` | Theme |
| `app.js` | Decks, study, intervals |
